# v0.1.0 发布候选清单

## 状态

- 候选版本：`v0.1.0`
- Git 标签：尚未创建
- 远端推送：尚未执行

## 源码包

发布包使用以下方式生成，确保没有 Git 元数据：

```bash
git archive --format=tar --prefix=voxorchestra-runtime-v0.1.0/ HEAD \
  > voxorchestra-runtime-v0.1.0.tar
```

最终标签确认后再生成正式包并在外部发布清单记录提交哈希、包大小与
SHA256。包哈希不能写入生成它自身的提交中。

## 包含

- C++17 源码、CMake、CTest 和非隐私固定测试数据；
- 默认无硬件依赖构建及泰山派硬件构建入口；
- 板端配置、预检、六进程启动和停止脚本；
- 架构、协议、部署、测试、benchmark、排障和演示文档；
- MIT License、第三方 NOTICE、版本链和脱敏发布证据。

## 排除

- `.git/`、`build-*`、对象文件、可执行文件和 CMake 缓存；
- 模型、厂商 SDK、外部源码、头文件副本和动态库；
- 稳定性原始归档、大型日志、中间 WAV 和现场麦克风音频；
- 板卡地址、开发机个人绝对路径、密码、令牌、私钥和其他凭据。

## 发布前最后动作

1. 复核候选提交和仓库状态；

3. 标签创建后重新生成源码包和 SHA256；
4. 用户另行确认是否推送分支和标签。

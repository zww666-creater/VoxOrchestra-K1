# 发布阻塞项与已知限制

## 阻塞项

当前没有阻止形成 `v0.1.0` 候选的功能门禁缺口。标签和推送尚未获得用户
授权，因此保持未执行；这属于发布动作门禁，不是产品故障。

## 非阻塞已知限制

1. DeepSeek-R1 单次回答约 30–60 秒，属于当前模型和 RK3576 的性能边界。
2. RKLLM Runtime 1.2.0 / RKNPU 0.9.8 存在长时运行劣化。
3. 麦克风当前固定采集 3 秒，不是 VAD 常驻流式输入。
4. REP 推理期间 cancel 无法插队；L0 路由承担停止/取消的快速路径。
5. Release 构建仍有测试 `chdir` 返回值和旧式 `zmq::poll` 的编译警告，
   不影响本候选构建和 45/45 测试，但应在后续维护中清理。

上述限制均如实保留，不伪装为已经解决。

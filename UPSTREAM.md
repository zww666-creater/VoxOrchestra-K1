# Upstream and attribution

VoxOrchestra-K1 is a K1/RISC-V adaptation of the VoxOrchestra project.

- Upstream: <https://github.com/Caden-1224/VoxOrchestra>
- Imported upstream revision: `b6e2cc0`
- Upstream license: MIT (`LICENSE`)

The complete upstream source and Git history are merged into this repository. The
upstream project remains credited according to its original license and notices;
this repository does not claim ownership of upstream code.

K1-specific changes are maintained separately so that platform-specific build and deployment logic remains easy to review.

## Scope

- K1/RISC-V build and deployment scripts
- K1 configuration
- portability fixes for dependency discovery
- CI portability checks and full source build

See the repository history for the individual K1 adaptation commits.
